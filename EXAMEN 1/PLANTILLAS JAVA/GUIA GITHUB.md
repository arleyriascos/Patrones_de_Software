SI VAS A SUBIR A GIT, HAY QUE USAR ESTOS CODIGOS EN LA TERMINAL

git init

git add .

git commit -m "primer commit"

git branch -M main

git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git

git push -u origin main


Escenario 2: Ya tienes el repo conectado (el que más vas a usar en el examen)

Si ya hiciste el paso anterior una vez y solo necesitas subir cambios nuevos, son solo 3 comandos:


git add .

git commit -m "avance del caso de estudio"

git push
